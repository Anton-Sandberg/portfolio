# Portfolio

Min portfolio hemsida. Byggd React, Vite, TailwindCSS och TypeScript.

## Live demo

Hemsidan:
[portfolio-antonsandberg.vercel.app](https://portfolio-antonsandberg.vercel.app)

API:
[https://antonsportfolio-e2czgddpg5byfwck.swedencentral-01.azurewebsites.net/api/PortfolioProjects](https://antonsportfolio-e2czgddpg5byfwck.swedencentral-01.azurewebsites.net/api/PortfolioProjects)

## Tech Stack

- **Framework**: React 19
- **Bundler**: Vite
- **Styling**: TailwindCSS
- **Animations**: Motion och TailwindCSS
- **Forms**: React Hook Form + EmailJS

## Kom igång

### Förkrav

- Node.js
- npm eller yarn

### Installation

```bash
git clone https://github.com/Anton-Sandberg/portfolio.git
cd portfolio
npm install
```

### Kör i utvecklingsmiljö

```bash
npm run dev
```
